# Changelog

## 0.1.2 - 2026-07-17

- First public release.
- Confines the Windows cursor to the PAYDAY 2 client area while the game is active.
- Releases cursor confinement when the game loses focus or is minimized.
- Recalculates the capture area after window, resolution, or display-mode changes.
- Includes English and Japanese end-user documentation and a Diesel 3.0 compatibility notice.
- Includes portable policy tests, PE verification, packaging scripts, and tagged GitHub Actions releases.
